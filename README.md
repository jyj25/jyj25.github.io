# 개인 포트폴리오

정적 HTML, CSS, JavaScript로 만든 개인 포트폴리오입니다. 기본 문서는 `index.html`이며 GitHub Pages에서 별도의 빌드 과정 없이 제공할 수 있습니다.

## GitHub Pages 배포

1. 이 파일들을 GitHub 저장소의 루트에 올립니다.
2. 저장소에서 **Settings → Pages**를 엽니다.
3. **Build and deployment**에서 **Deploy from a branch**를 선택합니다.
4. 배포할 브랜치(예: `main`)와 폴더(`/ (root)`)를 지정하고 저장합니다.

페이지 경로는 상대 경로를 사용하므로 `username.github.io/repository/` 형태의 프로젝트 페이지에서도 CSS와 JavaScript를 불러옵니다.

## 파일

- `index.html` — 기본 포트폴리오 페이지
- `styles.css` — 반응형 스타일 및 세 가지 색상 테마
- `script.js` — 브라우저 안에서만 동작하는 문의 입력 검증 시연
- `designs.html` — 디자인 시안 비교 페이지
- `concept-01.html`, `concept-02.html` — 다른 두 시안

문의 폼은 실제 메시지를 보내거나 저장하지 않습니다. 게시 전 이름, 작업 기록, 연락 방식 등 공개할 내용을 본인이 확인해 주세요.
